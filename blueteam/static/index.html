Multi-Layer Defense Architecture

  • L1 Input Guard: Recursive Base64/Hex/URL decoders, regex heuristic classifiers, delimiter injection inspection.
  • L2 Isolation: Cryptographic nonce envelope tagging, untrusted content framing, immutable security rules.
  • L3 Output Guard: Exact + regex canary matching, secret passphrase redaction, forbidden tool call interception.
